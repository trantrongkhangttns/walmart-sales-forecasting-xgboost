# Dataset: Walmart Sales Forecasting

The dataset used in this project is too large to be hosted on GitHub. Please download the `.csv` files from the official Kaggle competition and place them in this directory.

**Download link:** [Kaggle - Walmart Sales Forecasting](https://www.kaggle.com/datasets/anggundwilestari/walmart-sales-forecasting?select=stores+-+Walmart+Sales+Forecast.csv)

### Required files:
1. `train - Walmart Sales Forecast.csv`
2. `test - Walmart Sales Forecast.csv`
3. `stores - Walmart Sales Forecast.csv`
4. `features - Walmart Sales Forecast.csv`
